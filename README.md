# Block Blast: подсказчик и бот

Два инструмента с общим «мозгом» (`solver.js`). Он перебирает все варианты
расстановки трёх фигур во всех порядках и выбирает тот, где:

- больше очищенных линий и дольше держится комбо;
- остаётся меньше одиночных «дырок»;
- поле ровнее, без рваных краёв;
- остаётся место для самых неудобных фигур (3×3, палки 1×5 и 5×1, большие углы).

Один ход считается за 20–50 мс.

## 1. Подсказчик в браузере (любой телефон, включая iPhone)

Откройте `index.html` в браузере телефона.

**Быстрый способ: без скриншотов**
1. Один раз отметьте на поле занятые клетки, как в игре.
2. Каждый раунд нажимайте на три слота и выбирайте выпавшие фигуры.
3. Подсказка появляется сразу: три мини-поля показывают, какую фигуру, куда и в
   каком порядке ставить. Жёлтая обводка — линии, которые исчезнут.
4. Сделайте ходы в игре и нажмите «Я сделал эти ходы». Поле обновится само,
   и останется выбрать три новые фигуры.

**Способ со скриншотом**
1. Сделайте скриншот в игре.
2. В разделе «Распознать скриншот» выберите его.
3. Один раз подгоните оранжевую рамку по полю 8×8, а голубую — по зоне с тремя
   фигурами. Рамки запоминаются для этого размера экрана.
4. Нажмите «Распознать» и сверьте результат с игрой.

Совет: на Android удобно открыть игру и браузер в режиме разделённого экрана.

## 2. iPhone: подсказка по двойному касанию задней крышки

Скриншоты делать не нужно. В игре дважды коснитесь задней крышки iPhone, и
через секунду поверх игры появится её экран с нарисованными ходами: цифры 1, 2, 3
на поле и на фигурах внизу, а сверху три мини-поля с порядком ходов.

Как это работает: «Касание задней панели» запускает быструю команду, команда
снимает экран (в «Фото» он не сохраняется) и передаёт его скрипту в приложении
Scriptable. Скрипт (`ios/BlockBlast.js`) распознаёт поле и фигуры, находит лучшие
ходы и возвращает картинку, которую команда показывает через «Быстрый просмотр».

Настройка (один раз, около 5 минут):
1. Установите бесплатное приложение **Scriptable** из App Store.
2. На странице подсказчика откройте раздел «iPhone» и нажмите «Скопировать скрипт».
   В Scriptable нажмите «+», вставьте текст и назовите скрипт `BlockBlast`.
3. Сделайте один скриншот игры. Загрузите его в разделе «Распознать скриншот»,
   подгоните рамки и нажмите «Копировать настройки». Запустите BlockBlast в
   Scriptable: он сохранит настройки и покажет пробную подсказку.
4. Приложение «Команды» → новая команда из трёх действий:
   - «Снимок экрана»;
   - «Run Script» (Scriptable): Script — `BlockBlast`, Images — «Снимок экрана», Run In App — выключено;
   - «Быстрый просмотр».
5. Настройки → Универсальный доступ → Касание → Касание задней панели →
   Двойное касание → ваша команда.

Скрипт собирается из `solver.js`, `detect.js`, `ios/overlay.js` и `ios/template.js`
командой `node ios/build.js`.

Сам ставить фигуры на iPhone программа не может: iOS запрещает приложениям
нажимать в других приложениях.

## 3. Бот для Android (играет сам)

Нужно: компьютер (Windows, macOS или Linux), USB-кабель, Node.js 18+ и
[Android platform-tools](https://developer.android.com/tools/releases/platform-tools) (`adb`).

1. На телефоне включите «Для разработчиков»: Настройки → О телефоне → 7 раз
   нажмите «Номер сборки». Затем включите «Отладка по USB». На Xiaomi включите
   ещё «Отладка по USB (настройки безопасности)», иначе касания не работают.
2. Подключите телефон и разрешите отладку. Проверка: `adb devices` должен
   показать устройство.
3. Установите зависимости:
   ```
   cd bot
   npm install
   cp config.example.json config.json
   ```
4. Откройте игру и начните партию, затем выполните `node bot.js shot`. Появится
   `bot/screen.png`.
5. Загрузите `screen.png` на страницу подсказчика (раздел «Распознать скриншот»),
   подгоните рамки, нажмите «Копировать настройки для бота» и вставьте значения
   `screen`, `grid`, `tray` в `bot/config.json`.
6. Проверка без касаний: `node bot.js dry` печатает распознанное поле, фигуры и
   лучший ход. Если поле распознано неверно, поправьте рамки.
7. Один ход: `node bot.js once`.
8. Автоигра: `node bot.js play`. Остановка — Ctrl+C.

### Как бот подстраивается сам

- **Высота подъёма фигуры.** В игре фигура при перетаскивании висит над пальцем.
  После каждого хода бот смотрит, куда фигура встала на самом деле. Если она
  сместилась, бот исправляет `liftCells` и `offsetX` и сохраняет их в `config.json`.
  Если фигура упала мимо поля, бот перебирает другие значения подъёма.
- **Размер фигур внизу** (`trayCellRatio`) запоминается, когда видны все три
  фигуры.

### Если что-то не работает

| Проблема | Что сделать |
|---|---|
| `adb` не найден | Укажите полный путь в `config.json` → `"adb"` |
| Фигура не тянется | `"swipeMode": "motionevent"` (Android 11+) или увеличьте `"swipeMs"` до 700–900 |
| Бот спешит, игра не успевает | Увеличьте `"afterMoveMs"` до 1200–1500 |
| Неверно распознаются клетки | Точнее подгоните оранжевую рамку по краям поля |
| Не видит фигуры | Голубая рамка должна захватывать всю зону с фигурами и немного фона вокруг |

## Файлы

- `index.html` — подсказчик (открывается в браузере)
- `solver.js` — поиск лучших ходов (общий для страницы и бота)
- `detect.js` — распознавание скриншота (общий)
- `ios/BlockBlast.js` — скрипт Scriptable для iPhone (собранный файл)
- `ios/overlay.js` — рисование подсказки поверх снимка экрана
- `bot/bot.js` — бот для Android через ADB
- `sim.js` — симуляция партий для проверки силы алгоритма: `node sim.js 20 300`

## Честно о результате

Алгоритм играет сильно, но в Block Blast много случайности: иногда выпадают
фигуры, которые никуда не лезут. 4 миллиона очков — это очень длинная партия, и
никакой алгоритм не гарантирует её с первой попытки. Подсказчик убирает ошибки
расстановки, а это главная причина проигрышей.

Бота проверяли на эмуляторе экрана, а не на настоящем телефоне. На вашем
устройстве может понадобиться подогнать рамки и параметры перетаскивания (см.
таблицу выше).
