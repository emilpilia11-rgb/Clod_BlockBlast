iPhone: подсказка по двойному касанию

В игре дважды коснитесь задней крышки iPhone, и через секунду поверх игры появится её экран с нарисованными ходами. Скриншоты делать не нужно. Настройка займёт минут 5, делается один раз. Откройте эту страницу на самом iPhone.

  1. Установите бесплатное приложение Scriptable из App Store.
  2. Нажмите «Скопировать скрипт». В Scriptable нажмите «+», вставьте текст, сверху переименуйте скрипт в BlockBlast и нажмите «Done».
  3. Один раз настройте рамки: сделайте скриншот игры, загрузите его в разделе «Распознать скриншот» ниже, подгоните рамки и нажмите «Копировать настройки». Потом запустите BlockBlast в Scriptable: он сохранит настройки и покажет пробную подсказку.
  4. В приложении «Команды» создайте команду из трёх действий: Снимок экрана → Run Script (Scriptable): Script — BlockBlast, в поле Images — «Снимок экрана», Run In App — выкл. → Быстрый просмотр. Назовите команду «Подсказка BB».
  5. Настройки → Универсальный доступ → Касание → Касание задней панели → Двойное касание → «Подсказка BB».
  6. Играйте: двойное касание задней крышки → смотрите ходы → «Готово» → ставьте фигуры.

Распознать скриншот
  1. Сделайте скриншот в игре и выберите его ниже (или вставьте из буфера).
  2. Один раз подгоните рамки: оранжевую точно по полю 8×8, голубую по зоне с тремя фигурами. Тяните за углы или за середину. Рамки запоминаются.
  3. Нажмите «Распознать». Ошибки можно поправить нажатием на клетки.
